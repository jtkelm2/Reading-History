# Example crease patterns (FOLD format)

| File | What it is |
|---|---|
| `example1_running.fold` | The running pattern of the paper (84 creases, 32 interior vertices, unit pi/32). Coordinates are given to three decimals; it needs a tolerance of about 2e-3 rad, which the script finds automatically. |
| `example2_body.fold` | The body pattern of the paper (15 creases, 5 interior vertices, unit pi/4). |
| `komatsu_gentle_dragon.fold` | Hideo Komatsu's Gentle Dragon (278 creases, 103 interior vertices), from the example collection of Flat-Folder. |
| `bernhayes_45_crossover.fold` | The 45-degree crossover gadget of Bern and Hayes, unassigned, from the same collection. |

The last two files come from Flat-Folder by Jason S. Ku, https://github.com/origamimagiro/flat-folder
(MIT licence, Copyright (c) 2022 Jason S. Ku). The designs belong to their authors. The rest of the
collection can be fetched with `tools/fetch_flatfolder_corpus.sh`.
